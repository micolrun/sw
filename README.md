# 양돈 질병·사양관리 실무 자료

이 프로젝트는 양돈 농장 관리자와 현장 실무자가 질병 예방, 이상 징후 확인, 사양관리 개선에 필요한 정보를 빠르게 찾아 적용할 수 있도록 만드는 공개 자료실입니다. 수의사와 연구자는 근거 검토와 전문 감수에 참여합니다.

## 웹사이트

첫 화면에서 질병 관리, 사양 관리, 업계 소식, 시세·통계 분야를 탐색할 수 있습니다. 자료 검색과 분야 필터는 브라우저에서 동작합니다. 업계 소식과 시세는 현재 공식 정보원으로 연결되며, 자동 수집이나 실시간 수치를 제공하지 않습니다.

- `index.html`: 사이트의 화면 구조
- `styles.css`: 반응형 디자인
- `app.js`: 자료 목록, 검색, 필터, 상세 보기
- `.github/workflows/pages.yml`: `main` 브랜치 변경 시 GitHub Pages 배포

새 현장 자료는 `app.js`의 `articles` 목록에 제목, 분야, 대상 돈군, 요약, 점검 항목을 추가할 수 있습니다. 진단·치료 관련 내용은 전문가 검토 후 게시하는 것을 원칙으로 합니다.

## 현장에서 활용할 내용

| 분야 | 제공할 정보 |
| --- | --- |
| 질병 관리 | 주요 질병의 관찰 지표, 전파 경로, 감별 시 확인할 사항, 예방 및 발생 시 대응 절차 |
| 사양관리 | 번식돈·포유자돈·이유자돈·육성비육돈의 급이, 급수, 환경, 군 관리 점검 항목 |
| 위생·방역 | 출입 통제, 청소·세척·소독, 격리, 폐사축 처리, 기록 관리 절차 |
| 데이터와 자료 | 농장 기록 양식, 생산·건강 지표 해석 방법, 연구 및 지침의 현장 적용 요약 |

## 콘텐츠 작성 원칙

- **행동부터 제시합니다.** 각 문서는 현장에서 확인할 징후, 즉시 할 일, 담당자에게 보고할 기준, 후속 점검 순서로 작성합니다.
- **적용 조건을 명확히 합니다.** 성장 단계, 농장 유형, 지역, 계절, 질병 상황에 따라 달라지는 내용을 구분합니다.
- **근거와 시점을 표시합니다.** 지침·논문·공공 자료의 출처와 확인 날짜를 기록하고, 근거 수준이나 불확실성을 함께 설명합니다.
- **진단과 처방을 구분합니다.** 증상만으로 질병을 확정하지 않으며, 검사·진단·약품 사용·접종 계획은 담당 수의사와 해당 지역의 최신 기준에 따라 결정하도록 안내합니다.
- **측정할 수 있게 씁니다.** 권장 수치가 필요한 경우 단위, 측정 위치·방법, 적용 대상과 범위를 함께 적습니다.
- **현장 언어를 사용합니다.** 전문 용어는 처음 나올 때 풀어 쓰고, 표·체크리스트·작업 순서를 적극 활용합니다.

## 문서 기본 구성

새 주제를 작성할 때는 다음 순서를 권장합니다.

1. **한눈에 보기:** 대상 돈군, 핵심 위험, 우선 조치
2. **현장 확인:** 관찰할 징후와 기록할 항목
3. **실행 절차:** 담당자별 작업 순서와 주의점
4. **판단·보고 기준:** 수의사 상담, 검사 의뢰, 격리 등으로 이어지는 기준
5. **예방과 재점검:** 반복 발생을 줄이기 위한 관리 항목과 확인 주기
6. **근거 자료:** 출처, 확인 날짜, 지역별 적용 시 주의점

## 기여와 검토

주제 제안이나 오류 제보는 Issue로 남겨 주세요. 새 문서와 수정안은 Pull Request로 제출하고, 가능한 경우 현장 적용 조건과 참고 근거를 함께 적어 주세요. 질병 진단, 치료, 약품, 백신에 관한 내용은 전문가 검토를 거쳐 반영합니다.

이 자료는 농장 의사결정을 돕기 위한 참고 자료입니다. 개별 농장의 진단과 치료 결정에는 현장 정보와 담당 수의사의 판단이 필요합니다.
